# Vector Salud

Aplicación Streamlit para gestionar camas e insumos hospitalarios con vectores, matrices, sumatorias y una función cuadrática.

## Ejecutar en Windows

1. Instalar dependencias:

   ```powershell
   py -m pip install -r requirements.txt
   ```

2. Iniciar la aplicación:

   ```powershell
   py -m streamlit run app.py
   ```

También puede ejecutarse `run.bat`: instala dependencias, inicia la app y mantiene la ventana abierta si ocurre un error.

La aplicación se abre en `http://localhost:8501`.
